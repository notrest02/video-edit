## 4. 사용자와 정한 것 (판단 근거)
- **답 길이 한도 64000 유지**: 16000 이었을 때 실패가 반복된 적 있음 (AI가 속으로 생각하는 양 때문). 한도는 비용을 늘리지 않고 잘렸을 때 버리는 양만 정함. 토큰 기록을 몇 번 보고, 가장 많이 쓴 양의 1.5배 정도로 줄일지 판단
- **비용 어림을 다시 잡음**: 생각 토큰 포함하면 광고당 약 10~20원, 3개에 몇십 원 (앞서 "2~3원"은 생각 토큰을 빼서 틀렸음). 실제 숫자는 앱 표시·기록으로 확인
- **다른 광고 겹침은 약하게만** (완전히 끄지 않음). 사용자는 한 시퀀스에 광고 구간 3개로 한 번에 자동 배치함
- **지시문은 묶음별로**: 규칙끼리 영향을 줘서 한꺼번에 바꾸면 원인을 모르고 분석 시간만 늘어남. 바꿀 문장은 넣기 전에 먼저 보여 줌. 남은 묶음은 메모리 `prompt-rule-backlog`
  - 2묶음: ③ 순서 5번이 규칙 D와 충돌 ⑦ 이어 쓰기 남은 길이 ⑧ 2순위 빈칸 허용
  - 3묶음(하나씩): ① 예시가 전부 흡착식 건조대 ⑥ 사람 얼굴 금지 범위(R17·루시아이) ⑨ 광고 전체 같은 묶음 반복 제한(사용자 결정 필요) ⑩ 후킹 없는 첫 컷 기준
