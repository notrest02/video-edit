# AI 자동 배치 규칙 목록

사용자(편집자)가 요청한 컷 배치 규칙을 한곳에 모은 목록이다. **자동 배치 코드나 AI 지시문을 고칠 때는 반드시 이 목록과 대조하고, 규칙 시험을 돌린다.**

```
npm run test:rules                      # 규칙 시험 (일부러 어기는 상황 31가지)
npm run check:export -- <결과.mp4>      # 내보낸 영상 컷 검사: 짧은 장면(다음 장면 비침)·마스크 풀림·1프레임 번쩍임 → 의심 자리 사진
npm run test:checker                    # 컷 검사기 시험: 일부러 망가뜨린 영상(문제 6개 심음)·멀쩡한 영상으로 확인 (8가지)
node tools/auto-edit/replay-logs.mjs <프로젝트.agproj> <광고1 기록.json> ...   # 지난 자동 배치의 AI 답을 지금 코드에 다시 넣어 확인
```
AI 답 기록은 `%APPDATA%\antigravity-video-editor\auto-edit-logs\` 에 자동 배치할 때마다 광고별로 저장된다.

> 2026-11-08: 지시문을 새로 정리하다가 예전에 요청받은 규칙("같은 영상의 다른 부분 연달아 금지")이 빠져서 다시 나온 일이 있었다.
> 그 뒤로 규칙은 ① 이 목록에 적고 ② 숫자로 잴 수 있으면 코드·검사기로 막고 ③ 시험으로 확인한다.

## 어디서 지키는가
- **코드**: `src/utils/autoEdit.ts`가 직접 막는다. AI가 어겨도 다른 장면으로 바꾸거나 다른 컷 자리를 고른다. 확실하다.
- **검사기**: `auditPlan`이 결과를 보고 확인 목록(❌/⚠️)에 띄운다. 놓쳐도 사람이 볼 수 있다.
- **지시문**: `electron/autoEditAssign.ts`의 Haiku 지시문. **부탁만 한다** — AI가 가끔 어길 수 있다.
