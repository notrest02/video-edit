## 11. 버그 찾기 (11-16, 커밋 안 함)

방법: 별도 검토 에이전트(오늘 바뀐 코드만, 내 결론 안 줌) + 앱에서 직접 흐름 시험.

**앱 흐름 시험 — 모두 정상**: 저장→다시 열기, 클립 가운데 자르기(+되돌리기), 속도 바꾸기, 시퀀스 오가기, 인-아웃 구간 내보내기 계산 = 미리보기, '이 클립만' 전환(+되돌리기), 장면 바꾸기(+되돌리기), 새 프로젝트, 패널 버튼(+ 마스크 추가 → 원본, 이 클립만, 삭제), 미리보기 꼭짓점 끌기 → 같은 원본 다른 컷에도 반영 + 되돌리기

**검토에서 찾아 고친 것 (7개)**
1. 미디어 재연결하면 원본 마스크가 안 보임(경로 키가 옛 경로) → 내보내기에 원본 글자 그대로 나옴. `relinkAsset` 에서 키를 새 경로로 옮김 (앱에서 확인)
2. 장면 바꾸기: 클립에 남은 예전 자동 마스크가 새 장면에 엉뚱하게 남음 → 원본이 바뀌면 클립의 자동 마스크는 버림. 예전 방식 자동 마스크만 있는 프로젝트도 '자동 마스크 쓰는 중'으로 봐서 새 원본 글자 찾기
3. 원본 전체로 계산하면 화면 여러 자리를 뛰어다니는 글자(워터마크)가 그 자리들을 다 덮는 큰 상자 하나가 됨 → 자리가 뛰는 지점에서 나눠 계산 (`splitAtJumps`, R41 시험 ⑧)
4. 자동 마스크를 다시 넣을 때 예전 클립별 자동 마스크를 지금 시퀀스에서만 지워 다른 시퀀스는 두 겹 → 모든 시퀀스에서 지움
5. 장면을 바꿔도 마스크 패널의 '찾은 글자 목록'이 예전 원본 것으로 남아 새 원본에 잘못 적용될 수 있음 → 패널을 원본이 바뀌면 새로
6. 장면 바꾼 뒤 늦게 끝난 글자 찾기 결과: 되돌리기에 안 들어가고, 그사이 다른 프로젝트를 열면 거기에 들어갈 수 있음 → 클립·원본이 그대로일 때만 넣고 되돌리기 기록
7. 자르기·복사로 같은 id 의 '이 클립만' 마스크가 두 클립에 있을 때 하나를 원본으로 옮기면 id 가 겹쳐 지우기가 둘 다에 걸림 → 원본으로 옮길 때 새 id (R41 시험 ⑨)
